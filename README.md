## 🚀 Featured Projects

### 🎭 MoodSync &nbsp;[![Live Demo](https://img.shields.io/badge/Live-Demo-7c3aed?style=flat-square)](https://mood-sync-lovat.vercel.app) [![Repo](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/NovaWhisperer/MoodSync)

> **AI-powered mood detection meets music discovery**

MoodSync uses your webcam to detect facial expressions in real time using **face-api.js** — entirely in the browser, with no raw image data sent to any server. Based on your detected mood, it recommends matching songs served from a custom Express + MongoDB backend with media hosted on ImageKit.

**Stack:** React 19 · Vite · Tailwind CSS · Zustand · Framer Motion · face-api.js · Node.js · Express 5 · Mongoose · ImageKit · MongoDB Atlas

**Highlights:**
- 🧠 Browser-based emotion analysis — local-first, no webcam data uploaded
- 🎵 Mood-filtered song recommendations via REST API query params
- 📤 Song upload via multipart form data with ImageKit CDN storage
- 🌊 Smooth UI with Framer Motion animations and Zustand state management
- 🚀 Frontend on Vercel · Backend on Render · DB on MongoDB Atlas

### 🍽️ Recipe Atelier &nbsp;[![Live Demo](https://img.shields.io/badge/Live-Demo-7c3aed?style=flat-square)](https://recipe-atelier.vercel.app) [![Repo](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/NovaWhisperer/recipe-atelier)

> **A modern recipe management app — no backend required**

A feature-complete recipe manager where you can create, search, sort, filter, and export your recipes. All data lives in **localStorage** — no accounts, no server, just a smooth frontend-only experience built with React 19 and Tailwind CSS v4.

**Stack:** React 19 · Vite · Tailwind CSS 4 · React Router v7 · React Hook Form · React Context API · Nano ID

**Highlights:**
- 🔍 Real-time search across names, descriptions, ingredients, and chefs
- 📂 Category filtering, multi-sort (name, price, newest), and pagination
- ❤️ Favorites system with persistent local storage
- 📊 Live analytics: total recipes, average price, price range
- 💾 Import/export recipes as JSON — full backup and sharing support
- 🔄 Duplicate recipes with one click to create variations

### ⏱️ FocusFlow &nbsp;[![Live Demo](https://img.shields.io/badge/Live-Demo-7c3aed?style=flat-square)](https://focusflow-psi-tawny.vercel.app) [![Repo](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/NovaWhisperer/focusflow)

> **A productivity dashboard — zero dependencies, zero frameworks**

FocusFlow proves you don't always need a framework. Built with pure **Vanilla JS and SCSS**, it packs live weather (Open-Meteo API), a task board, a day planner with 18 hourly slots, a quote fetcher, a Pomodoro timer, dark mode, and full mobile responsiveness — all in a single HTML file.

**Stack:** Vanilla JS · SCSS · HTML5 · Open-Meteo API · dummyjson API · Remixicon · Google Fonts

**Highlights:**
- 🌤️ Live weather with temperature, humidity, wind, and precipitation
- ✅ Task board with importance flags and instant removal
- 🗓️ Day planner — 18 hourly time slots, persisted in localStorage
- 🍅 Pomodoro timer — 25 min focus / 5 min break cycles
- 🌙 Dark mode + weather/time-aware background theming
- 📱 Mobile-first with distinct portrait assets for small screens
